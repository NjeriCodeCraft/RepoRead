# RepoRead 🤖

AI-powered README generator that transforms any GitHub repository into beautiful, comprehensive documentation in seconds — powered by IBM Bob.

## 🚀 Live Demo
(https://repo-read.vercel.app/)

## ✨ Features
- Paste any GitHub URL and generate a README instantly
- One free trial — no account needed
- Save and manage your generated READMEs
- Copy to clipboard or download as README.md
- Clean, minimal dark UI

## 🛠️ Tech Stack
- React + Vite
- Tailwind CSS
- React Router
- IBM Bob (AI generation)

## 📁 Project Structure

RepoRead/
├── frontend/     # React + Tailwind frontend
